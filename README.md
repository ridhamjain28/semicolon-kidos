# KidOS — Adaptive Learning OS for Kids

KidOS is an intelligent, privacy-first learning environment for children aged 5–13. It leverages the **IBLM (Interaction-Based Learning Model)** to dynamically adjust content difficulty and topics based on real-time engagement signals.

## 🚀 The Vision
Most AI content for kids is generic. KidOS learns how a specific child learns—identifying if they are frustrated, bored, or highly engaged—and pivots the educational journey accordingly.

## 🏗️ Tech Stack
- **Backend:** FastAPI (Python)
- **Engine:** IBLM (Custom Logic)
- **Storage:** Supabase (Cloud Persistence)
- **Frontend:** Next.js / React (Modern UI)

## 📁 Project Structure
- `/backend`: FastAPI service & IBLM logic
- `/web`: Next.js frontend application
- `/docs`: Architecture & Progress tracking
